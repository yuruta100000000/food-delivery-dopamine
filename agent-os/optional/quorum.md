# quorum.md — 多数決検証(optional / **無効**)

status: DISABLED

## 何をするか
高リスクな変更(解析プロンプトの大改修など)に対し、verifierを3席(異なるseed/モデル)走らせ、
2/3以上のPASSで初めて通す。

## 導入条件(これを満たすまで入れない)
- verifier単独の誤PASS(後で人間がバグを発見)が **月2回以上** 起きた
- かつ、予算に3倍のverifierコスト($1.2/tick)を払う余裕がある

## なぜ今入れないか
現状はMAX_ITERS=1の手動ループで、人間が全レビューする(watch tier)。
人間レビューがある間、quorumは純粋なコスト増にしかならない。
